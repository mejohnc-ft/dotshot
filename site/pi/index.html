dotshot for Pi

Pi reads images with its read tool. Send it one from your Mac.

Pi keeps its toolset small, and its read tool handles images as well as text. Run Pi on your GPU box or build machine, send a capture with dotshot, and paste the path.

Set it up

Five minutes, nothing to install over there.

  1. Install dotshot on your Mac

    Download the notarized DMG from GitHub Releases and allow Screen Recording in its setup. Nothing gets installed on the other machine.

  2. Make sure this Mac can reach it with a key

    ssh -o BatchMode=yes dev@build-box true && echo ready

    No key there yet? Run ssh-copy-id dev@build-box once. Tailscale names and ~/.ssh/config aliases (including ones with a ProxyCommand) work, because dotshot uses your SSH configuration.

  3. Add it as a destination

    In setup, or from Terminal (or let your agent do it with the setup skill):

    DS=/Applications/dotshot.app/Contents/Resources/dotshot-capture.sh
"$DS" add build dev@build-box '~/inbound'
"$DS" check build

    check creates a private folder, verifies the key and SFTP, and saves the absolute path your agent will see.

  4. Capture

    Press ⌃⌥⌘S and drag, or ⌃⌥⌘V to record. The file lands on the machine and its absolute path is on your clipboard.
